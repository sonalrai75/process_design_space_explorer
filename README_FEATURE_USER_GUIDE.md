# Feature & User Guide

Adds a `/guide` page describing the current Process Design Space Explorer workflow and links it from both the main workspace and Cellularization page.

The guide covers:
- event-log loading and calibration;
- process inspection and missing-timing resolution;
- baseline stochastic simulation;
- Optimize Architecture Families and Manual SVD;
- manual and automated cellularization;
- virtual/physical/hybrid cell interpretation;
- structural analysis, controlled overflow, scheduling, and threshold sensitivity;
- saved cell designs and a recommended end-to-end workflow.

No backend or simulation logic is changed.
